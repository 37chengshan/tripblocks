# Optional media prompts

The shipped landing uses **no photographs**. Every visual is inline SVG/CSS:
a topographic route field, an abstract node-tree cut-out, two circular route
discs, and a tall trip-graph portrait. These prompts are only for swapping in
generated artwork later; the page must keep working without them.

## 1. Wide hero field — 2400 × 1357

> Editorial cartographic artwork on warm oatmeal paper (#f1eadf), extremely
> fine deep brown-plum ink contours (#2c2024), a single rust route line (#8e3d22)
> crossing the lower third, tiny map circles and delicate orbital rings. Quiet
> architectural studio light, generous negative space in the upper-left for a
> large Didone headline, no text, no letters, no logos, no animals, no
> photograph, no paper texture photo. Flat screen-print / plotter-drawing
> feeling, subtle grain, restrained contrast, premium travel journal. Leave the
> top 35% almost empty.

## 2. Circular route disc — 1:1, 1200 × 1200

> A circular editorial diagram on warm cream paper: one continuous rust route
> line (#8e3d22) winding through five small ink nodes, three thin orbital rings,
> a sparse dot grid, and tiny hand-set mono labels without readable words. Deep
> brown-plum ink on paper, one rust accent, generous margins inside the circle,
> no photograph, no animals, no gradients, no text, no logo. Screen-printed map
> plate, crisp hairlines, calm and exact.

## 3. Tall trip-graph portrait — 2:3, 1200 × 1800

> A tall editorial data-art portrait on deep brown-plum paper (#2c2024): seven
> cream day-nodes connected by a single rust route line, subtle topographic
> contours, one large orbital ring, little departure/arrival ticks, and a large
> ghosted numeral “07” in a high-contrast Didone serif. Warm cream and rust
> accents, no photograph, no animals, no people, no readable body text, no
> logo, no UI chrome. Museum poster / itinerary map, precise, quiet, premium.

## Negative prompt

`photograph, safari, elephant, animal, person, landscape photo, 3D render,
glossy, neon, gradient mesh, drop shadow, mockup, UI screenshot, text,
watermark, logo, busy collage`

## If a raster is used

Only the actual TripBlocks app/canvas screenshot may appear, as a small product
card inside a paper frame — never as the hero, cut-out, statement disc, or tall
portrait. Current fallback: no raster at all.
